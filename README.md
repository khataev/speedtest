# Speedtest

Консольная утилита для измерения скорости скачивания с указанного HTTP(S)-сервера. Для запуска достаточно Node.js 24+.

## Запуск

Справка

```bash
node speedtest.mjs --help
```

Замер: Подставьте прямой URL файла вместо адреса в примере. Файл должен скачиваться без промежуточных редиректов.

```bash
# Пример с использованием файла в 16МБ
node speedtest.mjs https://mirror.yandex.ru/debian/ls-lR.gz
Прогресс: 10.00%
Прогресс: 20.00%
Прогресс: 30.00%
Прогресс: 40.00%
Прогресс: 50.00%
Прогресс: 60.00%
Прогресс: 70.00%
Прогресс: 80.00%
Прогресс: 90.00%
Прогресс: 100.00%
Среднее время запроса: 2.89 с
Суммарный объём: 161.431460 МБ
Скорость скачивания: 44.72 Мбит/с
```

## Как работает замер

Скрипт выполняет 10 последовательных GET-запросов к одному URL и читает тело каждого ответа частями. Соединение по возможности используется повторно через keep-alive. На установку нового соединения отводится 10 секунд.

После успешной серии скрипт выводит три показателя.

- **Среднее время запроса (с)** — длительность от запуска GET до полного чтения тела, усреднённая по 10 запросам.
- **Суммарный объём (МБ)** — сумма прочитанных байтов тел ответов, выраженная в десятичных мегабайтах.
- **Скорость скачивания (Мбит/с)** — суммарный объём данных в битах, делённый на суммарное время запросов в секундах, с переводом в Мбит/с.

При ошибке запроса скрипт останавливает серию, сообщает номер попытки и причину и завершает работу с ненулевым кодом.
